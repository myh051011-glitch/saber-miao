## 聊天界面

底部「助手」进入独立聊天页：左右消息气泡、固定输入框、流式回答、图片/文件附件、历史会话、按主题分类。点击发送直接调用 DeepSeek，不再弹出申请聊天的确认。

历史按最近活动时间排列；长按会话可改标题和主题。搜索匹配标题、主题及每条消息前 512 字的索引。记录不再因超过 20 条而删除。0.3 当时仍保留的消息会迁移，原时间未知的明确标记；已经被旧版裁剪的数据无法恢复。

## 记忆和响应速度

- **新会话不发送其他会话聊天全文**。只加入相关习惯提示词（最多 500 字），以及开启的日程摘要。
- 当前会话最多取最近 6 条有效消息，文字摘要合计约 6500 字以内。图片不会随每次追问重复上传；要再看细节时重新附图。完整记录仍保存在本地。
- DeepSeek 在同一次回答末尾自动提炼最多 2 条习惯，目标每条 30 字以内，附本轮真实原话依据；没有新增信息不更新。同主题更新合并；只有单次证据标「待观察」，不同原话多次支持同一内容才标「多次提及」。
- 相关习惯由本地排序选出并限制长度；不另发一次摘要请求，减少调用、延迟和用量。习惯记录不会因为切换模型消失，也不会覆盖本轮明确指令。
- 完整长消息、文件文字和记忆快照在本地无损压缩；图片缩小并修正方向，只保留处理后的图片副本，原相册不受影响。附件数量多仍会占存储，不是无限免费云空间。
- 右上角菜单 → 个人记忆可查看依据、纠正固定、删除或关闭学习/使用；菜单也能查看当前问题会选用的习惯提示词。
- DeepSeek `/chat/completions` 本身无状态。应用负责长期记忆和检索，不是训练模型权重，也不把 DeepSeek 云端当作聊天备份。

思考强度可在右上角菜单选择，下一次请求生效：

| 档位 | API reasoning_effort | 本次输出上限（含推理） |
|---|---|---|
| 快速（默认） | none | 4000 tokens |
| 轻度 | low | 6000 tokens |
| 深入 | high | 16000 tokens |
| 最高 | max | 32000 tokens |

上限不是每次必然消耗量。更深的推理通常更慢、更贵；网络和服务负载也影响速度，无法保证固定秒数。流式显示正文，推理阶段显示状态，不把内部推理逐字当作回答显示。

## 用对话直接管理事项

例：「把高数复习改到明晚八点」「帮我安排周六下午两点运动」「完成这个任务」「删除刚才那件事」。明确的请求由助手生成结构化操作，应用校验后直接执行，附真实结果，不再点手动添加。对象或时间有歧义时要求助手在聊天中追问。

- 支持新增、修改时间/备注、完成、删除，每次最多 8 项，整批校验后写入。
- 新事项只有明确要求才开启随日提醒；不会擅自创建三星时钟闹钟。
- 当前列表不存在的 ID、归档事项、无效日期、过去的提醒、未知字段均拒绝执行。
- 仅明确对话请求可触发；按钮生成的每日建议不执行修改，附件里的命令也不应触发。模型仍可能理解错误，请查看执行回执。
- 右上角可撤销最近一次助手任务操作；之后任务已有其他更改时不整批覆盖，可通过对话改回。
- 删除 Canvas 待办会保存本地移除标记，避免下次同步复活，不会删除学校作业；完成不会替你提交作业。
- 「预约」只支持记成自己的本地日程。没有医院/场馆等接口，不能真实提交外部预约。

## 图片和文件

「＋」选择附件，发送前可移除。图片由当前官方支持视觉的 `deepseek-flash` 分析；其他模型会要求先切换。

- 输入：常见图片、PDF、DOCX、TXT、Markdown、CSV、JSON、ICS 和代码文本。
- 单文件最多 10MB，单次最多 3 个附件，总文字不超过 5 万字、图片不超过 8 张。
- PDF：支持文字提取时读取最多 80 页且最多 4 万字，超限要求拆分；只提取文字，不自动提取全部插图。扫描 PDF（或旧系统无法提取文字）仅分析前 5 页图像，选择后明确显示实际页数，模型也收到该限制。
- DOCX：提取文字，不含图片和复杂排版。暂不支持旧 `.doc`、`.xlsx`、`.pptx`，可先转 PDF/CSV。
- 输出：回答可保存 Markdown、TXT、PDF、PNG 长图；回答中的受支持代码块可导出 CSV、JSON、ICS 等文件。
- **PNG 是回答排版长图，不是文生图**；本版未接入独立绘画模型，不伪造图片下载链接。
- 所选附件内容会随问题发送给 DeepSeek；凭证不会作为附件或聊天内容发送。

## 长期保存与备份

聊天和习惯在手机应用私有存储中，按会话/时间保存，与模型 ID 分开。覆盖升级和更换模型保留；卸载或手机损坏会丢失本机数据。

菜单 → 导出聊天和记忆备份生成 ZIP，包含聊天、当前习惯、手动说明及本地附件，不包含 Canvas/DeepSeek 密钥。导入会新增会话、补充不存在的习惯主题，保留已有同主题记录；重复导入会产生重复会话。当前导入限制解压后合计 80MB，聊天元数据最大 30MB。备份不加密，请保存在自己的安全位置。本功能不是任务/课表的完整备份。

## Canvas 自动刷新与令牌

- 令牌持续加密保存在本机，**没有按天清除或每天必须更换的逻辑**。是否到期以学校 Canvas 账户 → 设置 → 令牌有效期为准，学校可能强制期限。
- 401：无效/过期/撤销，核对令牌；403：权限或学校访问限制，换令牌未必解决；断网或超时无需换令牌。本机没有你的凭证，不能替你确定当前令牌实际到期时间。
- 开启自动刷新后，打开应用或网络恢复时检查；同一小时成功后不重复请求，失败尝试有 15 分钟间隔。后台 JobScheduler 每小时安排联网任务，系统省电/强制停止可能延后，不能承诺整点送达。
- 保留「立即同步」用于手动检查。首次无法准确匹配时需选择一次当前 Canvas 学期。
- 普通作业在课程和个人待办下面，截止前 7 天重点提醒。Canvas 同步不会覆盖个人备注、完成状态和自定义安排。

|---|---|---|
| 2026-03-02—2026-07-03 | 2025—2026 春季 | 同济国际学生办公室 2026 春季报到指南 |
| 2026-07-04—2026-09-13 | 暑期小学期（个人划分） | 春季结束次日至秋季开始前一日 |
