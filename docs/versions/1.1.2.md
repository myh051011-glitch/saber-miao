# 1.1.2 版本归档

二级界面方正且说明小字过多；需头像与疲惫表情调整、月历课程数量恢复、隐藏已下课与已完成事项。

称呼改为御主；头像和疲惫图更新；圆角弹窗、设置折叠、精简文案；月历显示课程数；组件过滤结束课程和完成任务。

## 原始说明（原文保留）

# 尼尔机械济援 1.1.2

- 新生成的称呼、界面文案与天气提醒统一为「御主」。旧聊天原始记录不改写。
- 小组件使用用户新提供的 Saber 头像，背景匹配深蓝界面并去掉水印；疲惫表情使用去水印的独立图片，其余八种表情保留原图。
- 全局自定义弹窗、输入框使用深蓝圆角样式，日期和时间选择器使用统一主题。待办关闭提醒时隐藏提醒时间设置。
- 设置分组可展开；主界面、完整聊天、浮动助手、课表和小组件减少说明小字。计费、隐私、来源和后台限制等说明移入帮助或详情，错误及关键数据状态保留。
- App 本月以月历显示课程数量、待办和作业标记，点击日期查看详情；不展开整月列表。
- 小组件本月改为月历网格，日期可点击；今天和本周隐藏已下课的课程及已完成待办。
- 课程结束与跨日安排组件刷新，系统省电可能延后；打开 App 或手动刷新会按当前时间重算。

覆盖安装，勿先卸载。应用 ID 和签名沿用原版。组件若仍是旧布局，移除后重新添加。真机尺寸、圆角弹窗与触摸行为需要在 One UI 上验收。

GitHub 上传仍暂停。
