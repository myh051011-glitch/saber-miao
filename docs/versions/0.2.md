# 随日 0.2

面向个人三星手机的生活助手。Android 11 及以上。保持 0.1 的包名、数据存储和签名，直接覆盖安装；不要先卸载旧版。

## 本次新增

- 今天、本周、本月、日历、助手五个入口；本周按周一至周日，本月带日期网格。
- 今天包含当天、逾期和未定日期事项；周/月按计划日期筛选。课程只展示、不提醒。
- 待办可设置独立提醒日期和时分。完成、删除或关闭提醒后取消随日提醒。
- 4×4 桌面小组件，支持今天/本周/本月切换、快速新增、完成打勾、刷新及调整大小。列表按可用高度显示前几项，点标题打开完整列表。
- 手机时钟接口：带时间的事项可直接点击“创建闹钟”，交给手机时钟处理。标准接口没有年月日参数；对非下一次响铃日期会先提示。
- 同济 Canvas 只读手动同步：读取活跃课程及作业、截止时间、描述、提交状态；按课程和作业 ID 去重。
- DeepSeek 官方 API 问答、按需每日建议、Canvas 作业耗时分析、从 AI 回复提取待办草稿（保存前可编辑确认）。
- 个人记忆（最多 5000 字），可修改、清空；最近 20 条对话本地保存，发送最近 12 条供连续对话。

## 安装后设置

1. 安装上一级目录 SuiRi-0.2.apk，选择更新现有随日。
2. 设置 → 通知权限。需要准时提醒时，再开启“允许准时提醒”。未获准时权限时使用可能延迟的系统提醒，并在界面明确显示。
3. 设置 → 添加到桌面，按三星桌面提示确认。也可长按桌面空白处 → 小组件 → 随日。
4. 设置 → 配置 Canvas 令牌，在手机本地粘贴个人令牌 → 同步 Canvas 作业。
5. 设置 → 配置 DeepSeek API Key。默认模型 deepseek-flash，模型 ID 可修改。
6. 助手 → 个人记忆，填写作息、偏好和目标。发送前选择是否附带日程摘要。

Canvas 和 DeepSeek 凭证均以 Android Keystore 保护的 AES-GCM 加密保存，不包含在 APK 或源码中。Canvas 令牌只发送到 canvas.tongji.edu.cn，DeepSeek Key 只用于 api.deepseek.com。请求不跟随重定向，也拒绝外站分页链接。没有使用账户密码或共享浏览器登录状态。

## 提醒、闹钟及同步边界

- 随日提醒按 Asia/Shanghai 时间解释，在通知栏显示；不替代持续响铃的系统闹钟。
- 手机时钟创建的闹钟独立管理，随日打勾或删除任务不会自动取消它。在三星时钟中核对实际日期和重复设置。若装有多个时钟应用，系统可能提供选择器。
- 手机重启、升级或系统时间改变后重新安排提醒；仅对 24 小时内错过且未送达的提醒尝试补发一次，避免大量历史提醒。
- 用户强行停止应用、关闭通知或厂商省电管理可能影响通知和小组件，需重新打开应用并在 One UI 设置中检查。
- 桌面小组件请求 4×4 格子，实际尺寸由桌面网格决定。编辑/完成后刷新，系统周期刷新约 30 分钟且可能被延迟；可手动刷新。
- Canvas 是手动同步，不是后台持续监控。已提交的新作业不新增为待办；已存在的作业保留用户打勾状态，另显示提交状态。
- 老师修改截止时间时，已有提醒关闭并提示重新确认；用户自定义计划日期保留。同步未找到的旧事项保留并标记，不直接删除。
- Canvas 作业在本机被删除后，下次同步可能重新导入。单次读取全部可见活跃课程的作业；某一课程失败会报告整体失败，本次不覆盖原任务。
- AI 只能获得用户发送的问题、个人记忆、最近对话，以及可选的至多 60 项未完成待办摘要和未来 7 天课程。作业耗时分析会发送对应作业描述。
- AI 建议不是实际执行结果；不会自行提交作业、设置手机闹钟、修改记忆或读取微信/短信。AI 草稿不会自动开启提醒。
- 每日建议目前按按钮请求，不是每天定时推送。回复上限 1600 tokens，使用非思考模式控制用量；界面显示上次用量。真实费用以 DeepSeek 账单为准。
- 清空个人记忆不会删除历史对话；如需移除历史中的相关信息，也应清空对话。
- 没有云端同步或备份。卸载应用会清除本地数据和密钥。

## 构建和代码

PowerShell 执行 .\build.ps1。默认 SDK：D:\Androidsdk；JDK：D:\android\jbr。可传 -Sdk 和 -Jdk 参数。构建中间文件和个人签名保存在 ../../work/suiri-build，务必保留原签名，以便覆盖升级。

PowerShell 执行 .\test.ps1 运行功能检查；加 -Ics '课表文件绝对路径' 可运行针对用户样本的 9 项课表检查。需要已安装的 Android SDK Sources 36.1。测试从 SDK 复制 JSON 实现到工作目录，仅去掉安卓注解后在 JVM 运行，不修改 SDK。

app/src/main/java/com/example/suiri 中：
- MainActivity.java：界面、日期浏览、编辑与设置。
- TaskStore.java、TaskDates.java：数据和日期规则。
- Reminders.java、ReminderReceiver.java：待办通知调度。
- SuiRiWidget.java、res/layout：桌面小组件。
- Api.java、CanvasMerge.java：HTTPS 接口与 Canvas 合并。
- Secrets.java：加密凭证。
- TaskProposal.java：AI 待办草稿校验。
- Schedule.java：WakeUp ICS 解析。

本次 APK 使用已验证的 SDK 工具链脚本构建。Gradle 描述文件保留供后续整理，尚未验证 Android Studio Gradle 同步，也没有 Gradle wrapper。
