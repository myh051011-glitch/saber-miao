# saber喵 1.1.3

- 名称、启动入口、文件导出前缀和 APK 名称统一为 saber喵，Logo 使用用户提供的猫耳 Saber 图片。保留原应用 ID 和签名，覆盖安装保留数据。
- 新回复、界面及天气台词称呼改为「亲爱的master」，历史消息不改写。
- 助手顶栏改为「设置」，历史会话收入设置菜单。
- 和风天气支持手机系统定位：天气设置 → 定位当前位置 → 授权。在前台接收位置更新，按坐标查询天气，通过和风 GeoAPI 解析城市/区县。这里只显示天气所需的地区名，不承诺门牌级地址。
- 定位位于上海市外时，显示所在地与上海市区两份天气；区划未解析成功时仍显示上海作对照。位置过旧标为上次位置。拒绝权限可继续手动设置地区。
- 不持续后台追踪位置：退到后台停止位置监听，小组件和后台天气使用最近一次定位。旅行后打开 App 或在天气详情点击更新位置即可重新定位。
- 两地天气缓存独立；两地显示时实况/预警每2小时、预报每6小时；单地区实况每小时。定位解析与天气请求共享原每月3000次上限，未更换为无限请求。
- 助手回答下方「复制 / 保存 / 更多」→「保存 PPT」可导出标准 `.pptx`。建议提问“做一份PPT，每页用一级标题和3至5条要点”。文件为16:9深蓝金色、可编辑文字；长回答自动分页。此版不自动绘制复杂图表、嵌入图片或动画。

验证：182项JVM检查通过；示例PPTX经独立python-pptx读取、保存、重新读取，中文和特殊字符保留。手机位置授权、真实和风账号跨城查询、PowerPoint/WPS实际显示及覆盖升级仍需真机验证。
