# 随日 0.4

直接覆盖安装 SuiRi-0.4.apk，不要先卸载旧版。

1. 助手变成聊天界面：固定输入框、消息气泡、流式回复、历史会话和主题搜索。
2. 新会话不发送旧会话全文，只带最多 500 字习惯提示；DeepSeek 同次回答自动提炼新习惯，证据留本地。长消息和文件文字压缩存储，换模型仍保留。
3. 右上角「⋯」选择快速/轻度/深入/最高思考强度。默认快速，更深通常更慢、更贵。
4. 明确说新增、改时间、删除、完成任务会直接执行；菜单可撤销最近一次操作。对外预约未接入，只能创建本地日程。
5. 「＋」输入图片、PDF、DOCX、文本；回答可保存文本、PDF、PNG 长图和代码块数据文件。图片请用 deepseek-flash，PNG 输出不是 AI 绘画。
6. 聊天和记忆本地长期保存，可 ZIP 备份导入导出。旧版已裁剪的聊天不能恢复，卸载仍会清除本机数据。
7. Canvas 令牌不会按天清除；看学校设置的实际有效期。新增打开/恢复网络时检查、后台每小时自动刷新，受系统省电限制；认证与网络错误分别说明。
