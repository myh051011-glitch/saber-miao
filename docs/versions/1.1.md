# 尼尔机械济援 1.1

安装包：尼尔机械济援-1.1.apk。覆盖安装即可，勿先卸载；原应用 ID 和签名保留，以保留数据。启动入口明确设置新名称。如果三星桌面仍缓存旧名称，可移除旧快捷方式后从应用列表重新添加。

- 本月只显示计划、待办和重点标记，应用及小组件本月视图不显示课程。
- 新增「课表」入口，默认显示完整导入课表，显示星期、实际时间、地点和适用周次。可手动选择周次、修改第 1 周日期，选项保存在本地，不依赖当前系统日期切换周次。同一时段不同周的课程合并，点击查看完整详情；重叠时段分栏，可以横向滑动。
- 第 1 周默认参考导入课程所属学期的已知同济校历；不在已知校历范围时用首条课程所在周，用户可手动调整。未导入课程时显示导入提示。
- 今日课程按系统当前时刻显示未开始、上课中、已下课；前台每分钟检查，覆盖重复课程和跨午夜的状态计算。
- 4×5 小组件顶部 Saber 头像可直接打开天气开场的问答；外层空白及列表下方空白进入应用，原待办打勾与刷新操作保留。升级后如组件缓存旧布局，可移除后重新添加。
- 天气检查实况以及今日白天、夜间预报，关注降水概率、雷雨、雪冰、大风和最高最低温；可同时提示多项风险。数据缺失明确提示，不把当前晴天等同于全天无雨。天气台词由本地规则产生，无须额外调用 DeepSeek。
- Saber 新人格提示词另附草案，尚未启用。

和风天气仍需自己的 Host 与 API Key。沿用小时级实况/预警、6 小时预报缓存和每月 3000 次上限，不承诺服务商未来两年价格不变。日预报白天为 07:00–19:00，夜间为 19:00 至次日 07:00，并非逐分钟降雨预测。

验证：编译、签名与 167 项 JVM 检查通过，含真实 ICS 周次规则。启动入口名称和版本元数据已核对。手机上的布局、组件空白点击、升级数据、真实天气账户和三星后台行为尚待真机验证；后台组件更新由系统调度，可能延迟。

天气接口文档：https://dev.qweather.com/en/docs/api/weather/weather-daily-forecast/
