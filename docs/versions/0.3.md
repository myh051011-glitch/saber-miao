# 随日 0.3 更新说明

直接安装 SuiRi-0.3.apk 覆盖更新，不要先卸载。源码和安装包也会同步到桌面「随日项目」。

- 月历彩色标注安排、作业、课程和重点日期。
- 重点提醒在上，课程其次，个人待办与普通 Canvas 作业在下。
- 4×4 小组件显示今日/本周/本月课程和待办，支持滚动和打勾。
- Canvas 按当前学期筛选、每日联网刷新，截止前 7 天重点提醒。第一次同步后如提示学期不明确，在设置选择一次。
- 校历参考同济官网；两学期间隔按个人小学期处理。
- DeepSeek 可在对话中提出新增/删除/改写备注，预览确认后保存。
- 从对话逐渐学习生活与学习习惯，保留原话依据。单次待观察，多次支持才提高可信度；个人记忆页可纠正、删除或关闭。
- 升级首次打开显示更新日志。

新组件若显示异常，移除后重新添加。通知和后台刷新受手机省电设置影响；没有连接真机，实际显示和学校账号同步需在手机上验证。
