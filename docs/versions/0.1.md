# 随日 0.1：离线待办与课表

已生成安装包：上一级目录的 SuiRi-0.1.apk。面向 Android 11 及以上，包含 One UI 8 所用安卓版本。

## 安装与验证

把 APK 传到三星手机后打开，按系统提示允许该来源安装。如果电脑已连接并获手机 USB 调试授权，也可以使用 adb install -r 安装。

建议首次验证：新增任务 → 勾选 → 退出并重新打开 → 取消勾选 → 设置中导入课表 → 查看 2026-09-16 与 2026-09-23。

## 已完成的检查

- javac、D8、AAPT2、zipalign 构建成功；apksigner 验证通过。
- 使用用户提供的 ICS 通过 9 项检查：事件数、指定日课程数、隔周体育、11 月阶段课程边界、开课前、学期结束后，以及不支持规则的拒绝。
- Manifest 已检查应用入口、最低和目标系统版本。

## 本版边界

DeepSeek、Canvas、AI 排程、微信/短信、通知提醒和桌面小组件尚未实现。课表自带的提前提醒不会触发。任务日期是计划日期，没有具体时段或截止时间语义。ICS 暂支持该 WakeUp 文件使用的每周规则和上海时区；例外日期、全天事件及其他重复规则会提示不支持。导入课表为手动替换，没有实时同步。

应用数据保存在本机，卸载清除；本版尚无导出备份。此安装包使用个人开发签名，签名文件保存在工作目录 work/suiri-build，请保留它以便后续覆盖升级。

## 源代码与构建

app/src/main/java/com/example/suiri/MainActivity.java：界面、待办和文件选择。

app/src/main/java/com/example/suiri/Schedule.java：课表日期解析与每周重复判断。

build.ps1：已验证的离线构建入口，默认 SDK 为 D:\Androidsdk，JDK 为 D:\android\jbr，可通过参数修改。脚本使用工作目录 ../../work/suiri-build 保存编译中间文件和开发签名。

同时提供 Gradle 项目描述供后续 Android Studio 使用；本次未验证 Gradle 同步，也未附带 Gradle wrapper，APK 是通过上述 SDK 工具链构建的。
