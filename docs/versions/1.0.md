# 尼尔 机械济援 · 正式版 1.0

## 安装

直接覆盖安装 `Nier-1.0.apk`，不要先卸载旧版。同包名与原签名，旧数据由 Android 原地保留。版本号 1.0，内部升级序号5。

若旧桌面小组件布局未更新，先移除小组件，再长按桌面 → 小组件 → 尼尔 机械济援，重新添加4×5；移除小组件不会删除应用里的数据。三星桌面网格设置会影响实际尺寸。

## 这次增加

- 深蓝、金色界面，图3底部弹窗排版。
- 日程、周、月、日历与设置中的可拖动 Saber 头像；设置可收起/显示。
- 弹窗只展示当前台词；完整聊天记录在菜单「助手」。弹窗与完整页面共用当前会话。
- 九种本地表情和轻微呼吸动效；角色使用所给九宫格的彩色图块，尚非透明立绘或Live2D。
- Saber称呼「主人」，同一回复生成表情元数据，不额外调用模型。
- 4×5小组件，天气置顶，重点提醒优先于课程，其他待办与Canvas随后。
- 独立和风天气、Saber出行提示、天气通知和官方预警详情。
- 首次升级展示更新日志。原有课表、Canvas、聊天附件、习惯记忆、备份、任务修改与闹钟功能保留。

## 和风天气只需配置一次

1. 在 https://dev.qweather.com/ 注册并进入自己的控制台，按站内要求完成账户开通。不要购买付费套餐或启用自动充值。
2. 在项目中创建 **API KEY** 类型凭据；在控制台设置查看账号专属 **API Host**，通常类似 `xxxxx.qweatherapi.com`。不要用旧公共 `devapi.qweather.com`。
3. App → 设置 → 和风天气，填写 Host 和 API Key。Key不用发给助手，在手机上填入即可。它加密存于本机，不随源码或APK分发。
4. 地点默认上海市区；可输入自己的地点名称、纬度与经度。此版手动选位置，不会自动追踪手机位置。
5. 保存后联网，由系统安排首次获取；点天气条查看数据时间与错误原因。想接收通知，还要允许系统通知权限。

无需给应用三星天气的权限。官方预警详情保留发布机构、标题、时间与防御指南；Saber台词不替代原预警内容。

## 免费用量控制

实况和预警每小时最多1次，逐日预报每6小时最多1次。App与小组件共用缓存，每30天约1560次请求。每月本机硬上限3000次，失败和手动检查也计入，不用额外DeepSeek调用生成天气台词。

和风目前天气和基础服务前50000次/月免费，但不能保证未来两年政策不变；本机限额不约束同账号其他应用或清空数据后的计数。核对和风账户自身的消费控制/欠费规则。官方还提示2027年起API Key有每日请求额度限制，未来若限额不足可再迁移JWT。

官方定价：https://dev.qweather.com/docs/finance/pricing/
认证政策：https://dev.qweather.com/docs/configuration/authentication/
